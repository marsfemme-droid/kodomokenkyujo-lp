# こどもけんきゅうじょ LP

広告流入用の企業向けランディングページです。

## 構成
- `index.html`：LP本体
- `style.css`：スタイル

## 次に行うこと
1. メインビジュアル・ロゴを追加
2. お問い合わせフォームURLを正式URLへ変更
3. GA4 / Meta Pixelを設定
4. GitHub Pagesを有効化
5. 必要に応じて独自ドメインを設定

## GitHub Pages
Repositoryの `Settings` → `Pages` → `Build and deployment` で `Deploy from a branch` を選択し、`main` / `/(root)` を指定してください。
